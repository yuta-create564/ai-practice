上から順に進めてください。どこまで進めても、それまでの機能はそのまま使えます。

| 段階 | できるようになること | 必要なもの | 費用 |
|---|---|---|---|
| 0. 何もしない | Claudeの中のリンクで、練習・登録・まとめて登録・バックアップ | なし | 無料 |
| 1. 公開する | iPhoneのホーム画面から専用アプリとして開く・ネットなしでも開く | GitHub(作業済みのアカウント) | 無料 |
| 2. 同期する | スマホとMacで同じデータを使う | Supabaseのアカウント(新しく作る) | 無料の範囲 |

ChatGPT連携の手順は [CHATGPT.md](CHATGPT.md) にあります。

## 1. 公開する(ホーム画面アプリにする)

Claudeの中のリンク(claude.ai/artifact/…)では、ホーム画面の専用アプリやネットなしでの起動、同期は使えません。
そのため、アプリを GitHub Pages(GitHubの無料公開機能)で公開します。

> **他人に見えるもの・見えないもの**
> 公開されるのはアプリの「部品」(画面やプログラム)だけです。登録した単語や英文は、あなたの端末の中と、
> 2で作る同期先(本人しか読めない設定)にだけ保存されます。URLを知られても、あなたの学習内容は見えません。

### 1-1. 変更を main に入れる
1. GitHub でこのリポジトリを開き、Claude が作ったブランチ `claude/kind-planck-00z0mv` の
   プルリクエストを作って「Merge」します(Claudeに「プルリクエストを作って」と頼んでもかまいません)。

### 1-2. GitHub Pages をオンにする
1. リポジトリの **Settings** → 左の **Pages** を開きます。
2. **Build and deployment** の **Source** を **GitHub Actions** にします。
3. 上の **Actions** タブを開き、「アプリを公開」が緑のチェックになるまで待ちます(1〜2分)。
   動いていなければ、「アプリを公開」→ **Run workflow** を押します。
4. アプリのURLは次のとおりです。
   **https://yuta-create564.github.io/ai-practice/**

### 1-3. iPhone のホーム画面に追加する
1. iPhone の **Safari** で上のURLを開きます(Chromeなどではなく Safari)。
2. 下の **共有ボタン**(□に↑)→ **ホーム画面に追加** → **追加**。
3. ホーム画面の「英語暗記帳」アイコンから開くと、アドレスバーのない専用アプリとして開きます。

Mac では、Safari でURLを開き、メニューの **ファイル → Dockに追加** で同じようにアプリとして使えます
(Chrome の場合は、アドレスバー右の「インストール」ボタン)。

### 1-4. Claudeの中の版からデータを移す
iPhone のホーム画面アプリと、Safari や Claude の中のページは、保存場所が別々です。
1. 今まで使っていた Claude の中の版で **設定 → バックアップを作る → 文字でコピー**。
2. メモアプリなどに一度貼り付けて保存しておきます(念のため)。
3. ホーム画面アプリで **設定 → バックアップから戻す** に貼り付けて **戻す**。

### オフライン(ネットなし)で使えること
- 一度ネットにつないで開いたあとは、ネットなしでも開いて、練習・登録・編集ができます。
- ネットなしで変えた内容は端末に残り、同期を設定していれば、つながったときに自動で送られます。
- ※ 確認したのはパソコンの Chromium での動作です。iPhone 実機ではまだ確認していません(下の「確認してほしいこと」)。

## 2. 同期する(スマホとMacで同じデータ)

同期先には **Supabase**(スーパーベース)を使います。ログインと「本人のデータしか読めない設定」が
無料でまとめて用意できるためです。

### 無料プランの主な制限(2026年10月時点の情報)
- データベース 500MB(単語・英文なら数十万件分で、個人利用では十分)
- 無料で作れるプロジェクトは2つまで
- **1週間まったく使わないとプロジェクトが一時停止します。** データは消えません。
  Supabase の画面で「Restore」を押すと再開します。停止中もアプリは端末のデータで動き、再開後に同期されます。
- クレジットカードの登録は不要です。有料プラン(Pro)にしない限り請求は発生しません。

### 2-1. アカウントとプロジェクトを作る
1. https://supabase.com を開き、**Start your project** から GitHub アカウントでサインアップします。
2. **New project** を押し、次のように入れて **Create new project**。
   - Name: `eigo-anki`(なんでもよい)
   - Database Password: **Generate a password** を押す(このパスワードはアプリでは使いません)
   - Region: **Northeast Asia (Tokyo)**
   - Plan: **Free**

### 2-2. データベースの準備
1. 左のメニューの **SQL Editor** を開きます。
2. このリポジトリの [`supabase/schema.sql`](../supabase/schema.sql) の中身を全部コピーして貼り付け、**Run** を押します。
3. 「Success」と出れば完了です(何度実行しても大丈夫です)。

### 2-3. ログインの設定
1. 左の **Authentication** → **URL Configuration** の **Site URL** に
   `https://yuta-create564.github.io/ai-practice/` を入れて保存します(確認メールのリンク先になります)。
2. アプリの **設定 → 同期** に、次の 2-4 の2つを入れたあと、メールアドレスとパスワード(8文字以上)を入れて
   **初めて使う(アカウント作成)** を押します。届いたメールのリンクを押し、アプリで **ログイン** します。
3. **自分専用にするため、ほかの人がアカウントを作れないようにします。**
   **Authentication** → **Sign In / Providers**(または Settings)にある
   **Allow new users to sign up** をオフにして保存します。
   (オンのままでも他人のデータは見えない設定ですが、念のためオフにします。)

### 2-4. アプリに同期先を入れる
1. Supabase の左下 **Project Settings** → **API Keys**(または **Data API**)を開きます。
2. 次の2つをコピーします。
   - **Project URL**(`https://xxxx.supabase.co`)
   - **Publishable key**(`sb_publishable_...`)。表示がない場合は **anon public** キー(`eyJ...`)
3. アプリの **設定 → スマホとMacで同じデータを使う** に貼り付けて **保存する**。

> **入れてはいけないキー**: `secret` / `service_role` と書かれたキーは秘密のキーです。アプリにも GitHub にも入れないでください
> (アプリは秘密のキーを入れようとすると止めます)。
> Publishable key / anon key は公開されてよいキーで、データは「本人しか読めない設定」で守られています。

**全部の端末で入力を省きたいとき**: GitHub で `sentence-app/config.js` を開き、鉛筆ボタンで編集して
`supabaseUrl` と `supabaseAnonKey` に同じ2つを入れて保存(Commit)します。数分後に公開版に反映されます。

### 2-5. Mac とスマホの両方でログイン
同じメールアドレスとパスワードでログインすると、同じデータになります。

### 同期のしくみ(安全のための工夫)
- 端末に先に保存してから送るので、ネットが切れても、同期に失敗しても、端末のデータは消えません。
- 同じ項目を2台で変えたときは、**あとから変更したほう**が残ります。古い内容で新しい内容を上書きしません。
- 削除は「削除した」という印を送るので、別の端末からも消えます。
- 初めて同期する前の端末のデータは、自動で控えを残しています(設定画面からコピーできます)。
- 未送信の件数は、画面右上に表示されます。
