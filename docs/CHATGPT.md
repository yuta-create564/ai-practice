# ChatGPT から登録する方法

## 現在の状態
- **使える**: 「まとめて」画面への貼り付け登録。ChatGPT の回答を貼るだけで、複数件を確認してから登録できます。アカウント設定は不要です。
- **準備だけ完了(まだ接続していない)**: ChatGPT に「単語帳に追加して」と言うと登録される仕組み。
  アプリ側の登録の窓口・認証・重複防止はできています。ただし Supabase と GPT の設定が終わるまでは使えません。

## ChatGPT との連携方法は2種類(2026年10月時点で調べた内容)
| | 普通のChatGPTの会話 | 専用GPT(自分で作るGPT)+アクション |
|---|---|---|
| しくみ | 「アプリ(旧コネクタ)」の開発者モードで、MCPという方式のサーバーをつなぐ | GPTの設定に、登録の窓口(API)とキーを登録する |
| 認証 | 基本はOAuthという方式(ログイン画面つき)が必要 | APIキー(Bearer)が使える。キーはGPTの設定内に保存され、会話や公開コードには出ない |
| 使えるプラン | 開発者モードの対象プランが情報源によって違う(Business等のみとする公式記事と、Plus/Proも可とする記事がある) | GPTを作る機能があるプラン |
| 今回 | **作っていません**(ログイン画面つきの認証サーバーが別に必要で、対象プランも不確か) | **こちらで準備しました** |

普段の会話のまま使いたい場合は、当面「まとめて」画面への貼り付けを使ってください。
専用GPTを開いて「この単語を単語帳に追加して」と頼めば登録できるようにするのが、今回の方法です。

## 安全のための設計
- 会話を勝手に読み取ることはありません。GPT が送るのは、あなたが「追加して」と頼んだ単語・英文だけです。
- 登録の前には毎回、ChatGPT が「送信してよいか」の確認を出します(アクションを「重要な操作」に設定済み)。
- 「今日の会話から復習候補を出して」と頼むと、まず候補の一覧が出ます。選んだものだけが登録されます。
- キーはアプリで作った直後に1回だけ表示されます。サーバーには、キーを元に戻せない形(ハッシュ)でだけ保存します。
- キーを知らない人は登録も閲覧もできません。キーで読み書きできるのは、キーを作った本人のデータだけです。
- 同じ依頼が再送されても、1回分しか登録されません(依頼ごとの番号と、同じ内容のチェックの二重の防止)。
- 不要になったキーは、アプリの設定画面の「無効にする」ですぐに止められます。

## 手順
SETUP.md の「2. 同期する」が終わっていることが前提です。

### 1. 登録の窓口(Edge Function)を作る
1. Supabase の左メニュー **Edge Functions** → **Deploy a new function** → **Via Editor**。
2. 関数名を `eigo-api` にします(この名前でないとアプリの設定と合いません)。
3. 中身を全部消して、[`supabase/functions/eigo-api/index.ts`](../supabase/functions/eigo-api/index.ts) の中身を貼り付け、**Deploy function**。
4. できた関数の **Details**(または Settings)で **Verify JWT with legacy secret**(Enforce JWT Verification)を **オフ** にして保存します。
   (この窓口は、Supabaseのログインではなく、アプリで作る専用キーで本人を確認するためです。)

秘密のキー(service_role)は Supabase が関数に自動で渡すので、どこにも入力する必要はありません。

### 2. アプリで連携用キーを作り、接続テスト
1. アプリの **設定 → ChatGPTから直接登録 → 連携用キーを作る**。
2. **接続テスト** を押し、「接続テスト成功」と出ることを確認します。
3. **キーをコピー**。この画面を離れるとキーは二度と表示されないので、次の手順まで続けて進めてください
   (なくした場合は、新しいキーを作り直せば大丈夫です)。

### 3. 専用GPTを作る
1. ChatGPT(パソコンのブラウザが操作しやすいです)で **GPT** → **作成する(Create)** → **構成(Configure)**。
2. 名前: `英語暗記帳`(なんでもよい)
3. **指示(Instructions)**: アプリの **設定 → GPTに設定する内容 → 指示をコピー** を貼り付け。
4. **新しいアクションを作成する(Create new action)** を押します。
   - **スキーマ(Schema)**: アプリの **スキーマをコピー** を貼り付け(あなたの同期先のURL入り)。
   - **認証(Authentication)**: **APIキー** → 認証の種類 **Bearer** → APIキーの欄に手順2のキーを貼り付けて保存。
   - プライバシーポリシーの欄は、GPTを自分だけで使う場合は空でかまいません(公開する場合に必要です)。
5. 右上の **作成する** → 共有範囲を **自分だけ(Only me)** にして保存。

### 4. 動作確認
専用GPTで次のように頼み、確認画面で「確認(Confirm)」を押します。
- 「postpone を単語帳に追加して」
- 「I'm looking forward to it. をセンテンス帳に追加して」
- 「今日の会話から復習候補を出して」→ 番号で選ぶ

アプリを開くと(同期済みなら数秒〜1分で)「一覧」に出てきます。もう一度同じものを頼むと「登録済み」と返ってきます。

## 費用
- Supabase の Edge Functions は無料プランで月50万回まで呼べます(個人利用では十分)。
- GPTを作るには、GPT作成機能のある ChatGPT のプランが必要です。今のプランの画面に「GPTを作成する」があるか確認してください。
  ない場合はプランの変更(有料)が必要になります。変更するかどうかは、料金を確認してから決めてください。

## 困ったとき
| 表示 | 原因と対処 |
|---|---|
| 接続テスト失敗(401) | Verify JWT がオンのまま → 手順1-4でオフに |
| 登録の窓口がまだ公開されていません | 手順1ができていない、または関数名が `eigo-api` でない |
| GPTが「認証エラー」 | GPTの認証の種類が Bearer でない、キーの貼り間違い、キーを無効にした |
| GPTから登録したのにアプリに出ない | アプリでログインしているか、右上が「同期済み」かを確認。設定の「今すぐ同期」 |

## 技術メモ(窓口の仕様)
- `POST {Project URL}/functions/v1/eigo-api/items`
  本文 `{"request_id":"任意の文字列","items":[{"type":"word"|"sentence","en":"...","ja":"...","example":"...","note":"..."}]}`、最大50件
  返り値 `{"added":[...],"duplicates":[...],"errors":[...],"summary":"..."}`(再送時は `"replayed": true`)
- `GET .../eigo-api/items?q=検索語` 登録済みか調べる(自分のデータだけ)
- `GET .../eigo-api/ping` 接続確認
- ヘッダー `Authorization: Bearer eigo_...`
